### Таблица лицензий сторонних компонентов

Составлена по фактическому содержимому репозитория, а не по памяти:

- `core/lib/shapefile.py` — pyshp 2.1.0 (jlawhead), MIT
- `core/lib/shapefile123.py` — pyshp 1.2.3, форк под Python 3, MIT
- `core/lib/imageio/` — вендоренное подмножество imageio, BSD
- `core/lib/imghdr.py` — модуль stdlib CPython, PSF

Опциональные зависимости (GDAL, PyProj, FreeImage) определяются при импорте в
`core/checkdeps.py`.
