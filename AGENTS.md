# BlenderGIS — Agent Guide

## What this is

**This is not the original BlenderGIS project.** It is an **unofficial clone** of
[domlysz/BlenderGIS](https://github.com/domlysz/BlenderGIS), forked from upstream
v2.2.14 and developed independently. The original author does not sponsor or
endorse this fork. Credit for the original work belongs to
[domlysz](https://github.com/domlysz).

A Blender add‑on for geospatial data.  
It lives in the user add‑ons folder; **it is not a standalone Python package** (no `[build-system]` in `pyproject.toml`). It is loaded only inside Blender's Python runtime.

## Project goals

Keep these in mind for any change you make. They mirror the goals in `README.md`:

1. **Improve existing functionality** — fix bugs and make behaviour match its documentation.
2. **Optimize performance** — profile and speed up raster/vector parsing, triangulation, DEM handling, large imports.
3. **Add new functionality** — extend the feature set beyond upstream.
4. **Refactor for readability and modern Python standards**, without changing user‑facing behaviour.

Development is AI‑tool‑assisted. Changes are reviewed by a human maintainer.

## Feature flags

At the top of `__init__.py` (~line 30–43) there are module‑level flags (`BASEMAPS`, `IMPORT_SHP`, `GET_DEM`, …). Setting one to `False` completely skips the corresponding operator import and registration. **All are `True` by default.** If a lookup for an operator module fails, check the flag first.

## Entry points & boundaries

| Directory  | Responsibility |
|------------|---------------|
| `core/`    | Library – projection, raster, basemaps, vendored libs (`shapefile.py`, `imageio/`), settings |
| `operators/` | One `.py` per Blender operator panel. Conditionally imported via flags above |
| `prefs.py` | Add‑on preferences panel + config editing operators (CRS, OSM tags, servers) |
| `geoscene.py` | Scene georeferencing (CRS, origin coords stored as custom scene properties) |
| `clients/QtMapServiceClient.py` | **Standalone** PyQt6 app for batch tile download (not a Blender operator) |

## Dependencies

- **Runtime** (requires `bpy` from Blender, not pip‑installable): `requirements.txt` – numpy, pillow, tiffdata, pyqt6, requests, tqdm.
- **Dev/IDE stubs** (`pyproject.toml`): blender‑stubs, fake‑bpy‑module, mypy, pyproj, mathutils, etc.
- **Optional runtime libs**: GDAL, PyProj, PIL, ImageIO Freeimage. Detected at import in `core/checkdeps.py` — code falls back gracefully.
- `.venv` and `uv.lock` present. Run `uv sync` to install everything (may fail on blender‑stubs if not matched to your Blender version).

## Commands

```sh
uv sync                        # install all deps from pyproject.toml
uv pip install -r requirements.txt  # minimal runtime deps only
```

There are **no tests, no CI, no lint/typecheck scripts**.  
The only test‑like file is `core/lib/imageio/testing.py` (not a formal test suite).  
Ignore pytest — it is not configured.

## Quirks & gotchas

- **Indentation**: most files use **tabs**; `geoscene.py` uses **spaces**. Preserve whatever the current file uses — never globally reformat.
- **SSL verification disabled**: `__init__.py` sets `ssl._create_default_https_context = ssl._create_unverified_context` for HTTPS requests.
- **Logging**: writes to `~/.bgis/bgis.log` (rotating, max 512KB). Use the "Logs" operator in Blender to view.
- **Blender 5.x branching**: `prefs.py` uses `get_transform`/`set_transform` on `StringProperty` when `bpy.app.version[0] >= 5`, otherwise `get`/`set`.
- **`operators/__init__.py` stale reference**: `__all__` lists `io_get_srtm`, but the actual module is `io_get_dem`. The flag controlling it is `GET_DEM`.

## Secrets in `opencode.jsonc`

This file contains API keys for Hindsight and Context7 MCP. **Do not commit changes to it**; the `.gitignore` does NOT exclude it (`.opencode/.gitignore` excludes `node_modules` but not the root `opencode.jsonc`). If you modify it accidentally, revert before staging.

## External tool

`clients/QtMapServiceClient.py` is independent of Blender (PyQt6‑based). Needs `QtMapServiceClient.ui` in the same directory. Run with `python clients/QtMapServiceClient.py`.
